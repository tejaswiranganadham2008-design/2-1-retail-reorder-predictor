⚖️ AVL Rotations Guide

  • LL Case (BF > 1, Left Heavy): Single Right Rotation.
  • RR Case (BF < -1, Right Heavy): Single Left Rotation.
  • LR Case (BF > 1, Right Child of Left): Left Rotate child, then Right Rotate node.
  • RL Case (BF < -1, Left Child of Right): Right Rotate child, then Left Rotate node.

🧮 1. Moving Average Formula (Window = 3)

Forecast Demand = (Day 28 + Day 29 + Day 30) / 3
= (24 + 26 + 26) / 3 = 25.33 units / day

The algorithm takes the last 3 days of historical consumer demand to smooth out short-term noise and determine the daily run-rate.

⚖️ 2. Reorder Decision Rule

Reorder Threshold = Forecast Demand × Lead Time (Days)
Threshold = 25.33 × 2 days = 50.66 units
Current Stock = 14 units < 50.66 units
Decision: 🚨 REORDER TODAY

An item is immediately flagged for reorder whenever the current warehouse stock is insufficient to cover customer demand during supplier lead time.

About the Project & Academic Architecture

II B.Tech Mini-Project integrating AI, ADSA, OOPJ, and Python.

📌 Problem Statement & Motivation

Retail supermarket chains frequently face costly stock-outs on fast-moving everyday consumer essentials (milk, bread, eggs, cooking oil) due to manual, error-prone, and reactive reordering practices. This system replaces guesswork with an intelligent, data-driven automated pipeline that forecasts daily demand using machine learning time-series moving averages, organizes stock hierarchy via an AVL self-balancing tree for instant lowest-stock retrieval, and finds optimal restock paths across a multi-supplier logistics graph.
